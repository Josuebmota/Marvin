# curadoria — o Marvin instala as ferramentas por projeto

**Por quê:** ferramenta global é paga em toda sessão de todo projeto; a equipe barata só carrega o que o projeto usa.
**Pronto quando:** um projeto montado pelo Marvin tem as ferramentas dele no próprio escopo, e o perfil global fica vazio.
